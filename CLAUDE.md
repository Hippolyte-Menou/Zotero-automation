# Zotero Automation -- CLAUDE.md

## What this is

OpenAlex-powered literature discovery bot with two pipelines (gene-specific + topic-based), automatic Zotero upload, and a near-miss dashboard. Runs on GitHub Actions, no server needed. This is a **git submodule** of the Ophthalmogenetics vault -- commits here go to its own repo.

## Key concepts

### Gene pipeline (run.py --genes)
1. **Search pass** (bootstrap only -- skipped if gene already has Zotero papers): OpenAlex query using HGNC aliases + disease terms from `genes.yml` tags
2. **Citation expansion** (2-hop): backward refs + forward citations, scored by co-citation + bib coupling + recency bonus, adaptive threshold based on library size
3. **Recent papers pass**: current-year search bypassing citation threshold

### Topic pipeline (run.py --topics)
- Categories 1-4 (Anatomy/Embryology/Physiology/Examinations): keyword OR mode, scoped to ophthalmology subfield
- Category 5 (Pathologies): disease+clinical AND mode
- Nested Zotero collections mirroring vault structure

### Shared logic
- Text exclusion filters (cancer, tumor, mouse model, etc.)
- MeSH exclusion filters (Neoplasms, Diabetes Mellitus, etc.)
- Cross-pipeline dedup by PMID
- Provenance tags: `source:search`, `source:citation`, `source:recent`
- Batch Zotero upload (50 items/request, 60s timeout, 3 retries)

### Near-miss dashboard
- Articles considered but rejected (score below threshold, text/MeSH exclusion, mention filter)
- Static site deployed to gh-pages after each run
- Features: sidebar navigation, search, reason filter, BibTeX export

## CLI reference

```bash
python run.py                          # both pipelines
python run.py --genes                  # all genes
python run.py --genes CRB1 RHO        # specific genes
python run.py --topics                 # all categories
python run.py --topics anatomy         # single category (alias)
python run.py --topics "1 - Anatomy"   # single category (full name)
python build_genes_yml.py              # regenerate genes.yml from vault
python generate_test_data.py           # synthetic dashboard test data
```

## Scoring formula (citation expansion)

```
effective_score = co_citations + bib_coupling_bonus + recency_bonus

adaptive_min_co = min(max_min_co, max(min_co_citations, floor(log2(library_size))))
```

- `bib_coupling_bonus`: min(shared_references_with_seed_set, 3)
- `recency_bonus`: max(0, 3 - (current_year - paper_year))
- Defaults: min_co_citations=1, max_min_co=6
